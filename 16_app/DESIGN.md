# 16_app — fusion pipeline as ComfyUI nodes (design, 2026-10-26)

Scope: every 15_fusion stage (`tools/fusion/piece_runner.py`: audio -> stills -> type -> shots -> alpha -> depth -> compose
-> assemble -> final) runs inside ONE ComfyUI prompt on the box (RTX 5090 32 GB, 12 cores, Linux). The web page fills it by
`_meta.title`. Existing modules are wrapped, not rewritten. Where a node needs logic that lives inside a `Piece` method, that
logic is lifted into a new pure-function file, and piece_runner.py is left as it is.

Design-pass findings: LTX weights are already int8-convrot (no fp8 swap; sage attention is the lever). Compose's torch
backend is not effectively used today (each op round-trips to numpy; runner forced numpy) — call the ops' `.raw` variants
to stay on CUDA. ACE `keyscale` is a Combo input, so a dedicated `MographMusicEncode` node does the tokenize.

## 0. Key decisions
- **Rules write the piece spec; Qwen only writes a brief.** design_llm_8b on the box (`DesignLLM_Advanced`) returns a
  ~200-token JSON with the creative text: scene, still prompt, one motion line per shot, music tags/bpm, a technique enum,
  a mood enum, palette hints and a signoff line. Code decides everything else: words -> lines, beat-locked timing,
  modules/fonts/io styles, camera, shot layout, frames, seeds, type passes, compose recipe (planner rule as in
  `mograph/brief.py`). With no brief (draft, or bad output) the rules fill every field. Given (request, music analysis,
  brief text) the spec is a pure function. Seeds per sub-task come from `zlib.crc32(f"{seed}:{tag}")`, like `brief._salt`.
  The brief text is stored in `piece_json`, so any run replays exactly with `MographPieceFromJSON`.
- **Shot count: 6 fixed shot slots with lazy gating** (section 3). The graph is generated by a script from the box-proven
  `ltx_ic.build()` graphs.
- **Across node boundaries:** uint8 CPU tensors inside custom types. Work inside a node (compose, decode) stays on the GPU.
  Models stay resident.
- **Type passes run as a `type_passes.py` subprocess**, not in-process multiprocessing (spawned workers would re-import
  ComfyUI `main.py`). The 1088x1920 compose layers render asynchronously while LTX runs.
- **All app shots use the union-control IC graph** (`ltx25_ic_control.json`, two-stage 1152x2048). One LoRA for every shot
  = a single patch; Alpha-Gen is the only LoRA swap, done once after all shots. i2v shot kind (P01, P06-P10) is a
  nice-to-have slot variant.

## 1. Mograph nodes (new package `nodes_fusion/`, comfy_api v3 `io.ComfyNode`, same pattern as `nodes.py`)
Custom types (`nodes_fusion/_types.py`):
- `MOGRAPH_REQUEST`: dict of the app inputs.
- `MOGRAPH_MUSIC`: same keys as piece_runner `analysis.json` (cut, nframes, bpm, bar_len, key, beats, downbeats,
  chord_changes, curves, music_end).
- `MOGRAPH_PIECE`: the P*.json schema plus `layout{sid:{start,frames,xf}}`, `sizes{control,type,compose}`, `technique`,
  `quality`, `brief`.
- `MOGRAPH_TYPE`: {dir_control, dir_layers, manifest, job: Popen|None}, with `.wait()`.
- `MOGRAPH_CLIP`: {u8: torch uint8 [T,H,W,C] on CPU, sid, start, fps}.
- `MOGRAPH_CLIPS`: list of `MOGRAPH_CLIP`.

## 2. Graph `app/graphs/fusion.json` (generated by `tools/app/build_graphs.py`)
```
IN words (PrimitiveStringMultiline)  IN scene / IN music / IN look / IN quality (PrimitiveString)
IN length / IN seed (PrimitiveInt)   IN image (MographOptionalImage)  IN audio (MographOptionalAudio)
  -> MographRequest -> MographFusionBriefPrompt -> DesignLLM_Advanced (design_llm_8b, keep_model_loaded false) -> brief
ACE:   UNETLoader(acestep_v1.5_turbo) -> ModelSamplingAuraFlow(shift 3);  DualCLIPLoader(qwen_0.6b/1.7b_ace15, ace)
       -> MographMusicEncode -> ConditioningZeroOut;  EmptyAceStep1.5LatentAudio(seconds <- MusicEncode)
       -> KSampler(8 steps) -> VAEDecodeAudio(ace_1.5_vae) -> MographMusicCut -> MographMaster
       -> MographPiecePlan(request, music, brief)
       CLIPTextEncode(still_prompt) ConditioningZeroOut EmptyLatentImage(1088x1920) KSampler VAEDecode
       -> MographFirstFrame -> PreviewImage "OUT still"
MographTypePasses -> PreviewImage "OUT type"
Shared LTX: UNETLoader(ltx-2.5-22b-distilled int8-convrot) CLIPLoader(gemma4-12b int8, ltxv) VAELoader(video, audio)
       LatentUpscaleModelLoader(x2) LTXICLoRALoaderModelOnly(union-control) CLIPTextEncode(neg)
slot k: MographShotSlot -> CLIPTextEncode(prompt) LTXVConditioning ResizeImageMaskNode(control) GetImageSize
       ComfyMathExpression(frames <- slot.frames) ImageFromBatch ResizeImageMaskNode(first) LTXVPreprocess
       EmptyLTXVLatentVideo LTXVImgToVideoInplace(bypass <- no_first) LTXAddVideoICLoRAGuide(strength <- guide)
       LTXVEmptyLatentAudio LTXVConcatAVLatent RandomNoise(seed) CFGGuider KSamplerSelect ManualSigmas(8)
       SamplerCustomAdvanced LTXVSeparateAVLatent LTXVCropGuides LTXVLatentUpsampler LTXVImgToVideoInplace
       LTXVConcatAVLatent RandomNoise CFGGuider ManualSigmas(3) SamplerCustomAdvanced LTXVSeparateAVLatent
       -> MographDecodeClip -> clip_k
MographFootageGather(clip_1..6 lazy)
alpha k: LTXICLoRALoaderModelOnly(alpha-gen-0.9, 1 shared) + ltx25_ic_v2v chain (ResizeImageMaskNode 576x1024 ...
       EmptyAudio VAEEncodeAudio LTXVSetAudioRefTokens ... SamplerCustomAdvanced LTXVCropGuides) -> MographDecodeClip(gray)
depth k: LoadVideoDepthAnythingModel(vits, shared) -> VideoDepthAnythingProcess(fp16) -> VideoDepthAnythingOutput(gray)
MographCompose(matte_k / depth_k lazy) -> MographAssemble -> SaveVideo "OUT final"
```
- **Builder rewiring.** `build_graphs.py` calls `ltx_ic.build("control", two_stage=True, size=(1152,2048))` and
  `build("alpha", size=(576,1024), png=False)`, then rewires:
  - drops node 15/16 (LoadVideo / GetVideoComponents): 17.input <- slot.control;
  - 23 (LoadImage) -> slot.first; 26 -> slot.no_first; 14 -> slot.frames; 6.text, 35/53 seeds, 32.strength <- slot outputs;
  - replaces 60-62 with MographDecodeClip;
  - prefixes per-slot ids `c{k}.` / `a{k}.` / `d{k}.`, keeps loaders shared, runs `ltx_ic.check_graph` on the result.
- **Title contract.** Inputs: `IN words`, `IN scene`, `IN image`, `IN audio`, `IN music`, `IN length`, `IN look`,
  `IN seed`, `IN quality`. Outputs: `OUT still`, `OUT type`, `OUT final`. Look options from route
  `GET /mograph/api/looks`: `auto` + families by module base class:
  - strand: lanes, pipework, circuit
  - mech: depth_echo, hollow_tubes, topo_tower, hinge_unfold, xray_unfold, candy_orbit, depth_tunnel
  - slab: beat_bars, bold_thin_echo, gradient_fade, scale_clash, slats, solid_hollow, staircase
  - stack: spectrum, tangent_spray
  - ring: fly_into, outflow
  - voxel: voxel_orbit, voxel_roll
  - particles
- **Planner rules** (`plan_rules.py`):
  - Lines = `auto_lines(words)`; bar-aligned windows proportional to letter count, >= 1 bar each, `hit_on` 'bar'; last
    ~1.2 s kept for the signoff.
  - Look picks the family; seed picks modules within it. Energy (bpm, onset density) picks form_in/form_out (calm:
    lines/blobs; kinetic: flicker), `beat_orbit` params (P01 calm set vs P02 default) and fonts (`font_registry` mood
    tags, <= 3 per piece).
  - Technique from the brief, else scene keywords (mist/smoke/glass/silk -> behind, contour/landscape -> traced, else
    built_in) -> recipe from `tools/fusion/recipes/`:
    - `built_in.json` (P02): control depth, guide 1.0, VDA depth, tint_type + depth_occlude;
    - `behind.json` (P01): control depth guide 0.4, scene prompt with a subject, + Alpha-Gen + sandwich;
    - `traced.json` (P04): control line, no depth/alpha.
    Timeline keys rescaled to the cut.
  - Shots: frames <= 121 (proven; 145/193 benchmark options). N = ceil((nframes - xf) / (frames - xf)), xf = 12.
    24 s -> 6 shots. First frame = `last:s{k-1}`.

## 3. Variable shot count in a static graph
| option | for | against |
|---|---|---|
| A. 6 fixed slots, lazy-gated (`lazy=True` + `check_lazy_status` in Gather/Compose/ShotSlot.prev) | stock LTX nodes as proven on the box; every node visible and timed; shared loaders load once; generated graph | ~320 nodes; hard cap 6 (= 24 s at 121 f) |
| B. One node looping sampling inside (calls LTX node classes from Python) | exact N; can order TE/LoRA, free RAM | re-implements the graph by hand; untestable locally; hides "built with ComfyUI" |
| C. Batching shots | one sampler call | chained first frames are sequential; 32 GB can't hold B>1 at 1152x2048 |
| D. Node expansion (`enable_expand`, `NodeOutput(expand=GraphBuilder)`) / loop packs; subgraphs | exact N, small graph | subgraphs flatten (still static); expansion has outer-link + cache-dedupe unknowns (loaders could reload 22 GB) |

**Recommendation: A.** Only option that runs the exact graphs v002 already rendered. Lazy inputs aren't pulled into the
execution list unless requested (`comfy_execution/graph.py add_node`, `include_lazy`), so inactive slots never execute.
Gather makes every alpha/depth wait for all shots: one LoRA swap, no transformer ping-pong. D is the v2 path.

## 4. Speed
- **Residency/order:** Qwen 8B FP16 (~17 GB, unloaded after) -> ACE (~6-8 GB) -> MOSS-Image -> LTX 22B int8
  + Gemma-12B int8 TE + VAEs. LTX stays resident for all shots, then one alpha LoRA patch. Compose (~0.5 GB) runs with
  LTX loaded; `soft_empty_cache()` before compose.
- **GPU tensors:** compose uploads uint8 footage/type/matte/depth once per frame; op chain stays CUDA via `fn.raw` (ops
  without `.raw` — `fill_holes`, EdgeTracer `_step` — detour to numpy); one pinned download per output frame. DecodeClip
  converts to uint8 on GPU; clips off-GPU between nodes. RAM: float32 shot = 3.4 GB and ComfyUI caches outputs -> uint8
  types + `--cache-ram 24`.
- **Weights/flags:** LTX/Gemma already int8-convrot (no model changes this week). A/B `--use-sage-attention` on one shot
  (needs sm_120 build). No torch.compile.
- **12 cores:** type subprocesses procs=10, `OMP/MKL/OPENBLAS_NUM_THREADS=1`; layers job overlaps stills + LTX. Compose
  prefetches type PNGs with 3 threads; libx264 all cores. NVENC (`h264_nvenc -preset p5 -tune hq -rc vbr -cq 18`) only if
  listed by `ffmpeg -encoders` and a 1-frame probe works.
- **Expected minutes** (baseline = v002 state.json; new = estimates, BENCH.md confirms):

| stage | P02 baseline (35 min) | new, 12 s built_in (3 shots) | new, 24 s behind + mech look (6 shots) |
|---|---|---|---|
| Qwen brief / ACE + cut + master | - | 0.8 / 0.5 | 0.8 / 0.6 |
| still | 1.7 | 0.6 | 0.6 |
| type control (blocking) / layers (async) | 3.2 | 0.3 / (1, hidden) | 1.5 / (8-12, mostly hidden) |
| LTX load + shots | 11.4 | 1 + 3x2.0 | 1 + 6x2.0 |
| alpha / depth | - / 10 | - / 0.6 | 6x1.2 + 0.5 swap / - |
| compose / assemble + encode | 8.9 / 5 | 0.8 / 0.3 | 2 / 0.5 |
| **total** | **35** | **~11** | **~27** (baseline heavy piece 3.5 h) |

## Spike results
- **Lazy gating works (2026-10-26, local ComfyUI 0.19.3, `nodes_fusion/_spike.py`, driver `tools/app/spike_lazy.py`).**
  3 stand-in slots (`ShotSlot` with lazy `prev` -> `Work` (0.2 s sleep) -> `Gather` with lazy `clip_1..3`), piece with
  N = 1: executed exactly `slot s1, work s1, gather(s1)`; slots/works 2-3 never ran (not in the execution list, no
  validation error either). N = 2 and 3 run in order `slot k (prev = s(k-1)), work k`, then Gather. PASS for N = 1, 2, 3.
- **Rule for the real nodes:** `check_lazy_status` may only request inputs that are *wired*. Requesting an unlinked
  lazy input raises `NodeInputError` (execution.py, `make_input_strong_link`), and an unwired optional input looks the
  same as an unevaluated one (both `None`). Gather therefore declares `hidden=[Hidden.prompt, Hidden.unique_id]`
  (works inside `check_lazy_status`) and requests `clip_k` only if `k in piece.layout` AND `clip_k` is linked in its own
  prompt entry. That is what lets the draft graph (no LTX chains, `clip_k` unlinked) and the full graph share the node.
  Slot k>1 requests `prev` (always linked in the generated graph); slot 1 never does.
