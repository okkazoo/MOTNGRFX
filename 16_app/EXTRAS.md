## 2. One-click model download for the detected tier
- Today the user installs once by hand (README "Install"): node packs + `pip install -r requirements.txt`, then
  `python scripts/download_models.py --comfy /path/to/ComfyUI`, which scans the shipped graphs for model filenames, files each
  into `models/<folder>/` and skips what exists. Alpha-Gen is gated on
  Hugging Face (the user's HF token + licence acceptance).
- Extra: a "Download models for this machine" button calling a node-pack route that runs the same downloader for the detected
  tier, with progress on the page. Or: embed model URLs in the shipped graphs so ComfyUI's own missing-models dialog offers them.

## 3. Run on any ComfyUI machine (already works) / Comfy's cloud (unverified)
- The app only talks to ComfyUI's API (`/upload`, `/prompt`, websocket progress, `/view`, `/history`), so it already runs
  against any ComfyUI server with the pack + models: own PC, LAN machine, rented box (the 3060 runs went through an ssh
  tunnel). An extra would be a "server URL" field + connection check on the page.
- Comfy's own cloud: unverified. It only works if Comfy hosts our custom node pack.
